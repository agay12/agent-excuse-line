The excuse an agent gives after it breaks the build: reframed as early risk detection, ahead of schedule and at no extra cost.
The program writes it to `/output/entry.txt`, byte-identical on every run.

## Run it

```sh
node main.ts          # writes entry.txt to $MAKEFUN_OUTPUT_DIR or /output
```
